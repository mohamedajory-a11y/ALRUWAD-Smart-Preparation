# كراسة تحضير الرواد الذكية 👑

منتج قيد التطوير لمعلمي ليبيا: تحضير آلي من المناهج الليبية، تعديل وحفظ دون اتصال، تصدير Word/PDF، اشتراكات ودفع محلي.

## الحالة الحالية
- أندرويد تجريبي v0.3: إدخال وحفظ وتعديل وبحث ونسخ احتياطي محلي، ونموذج درس المحددات.
- **غير متوفر بعد:** التوليد الفعلي بالذكاء الاصطناعي، تسجيل المستخدمين، الاشتراكات والدفع، التصدير الأصلي Word/PDF، والمزامنة السحابية.
- تجنب حذف التطبيق قبل نقل النسخ الاحتياطية؛ لا توجد مزامنة سحابية حاليًا.

## الخطة التجارية
[اقرأ خطة الإطلاق في ليبيا](docs/LIBYA_COMMERCIAL_LAUNCH.md)؛ الأسعار والبوابات المقترحة غير نهائية ولا يوجد دفع فعلي في النسخة الحالية.

## بناء أندرويد
افتح GitHub Actions → Build ALRUWAD Android APK، وبعد نجاح البناء نزّل artifact الذي يحتوي على app-debug.apk.
