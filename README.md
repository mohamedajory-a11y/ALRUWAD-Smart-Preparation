# كراسة تحضير الرواد الذكية

مشروع أندرويد تجريبي (v0.2) لمركز رواد المستقبل.

## البناء
من تبويب Actions افتح Build ALRUWAD Android APK ثم نزّل ملف الـ artifact بعد نجاح البناء. سيحتوي على `app-debug.apk`.

## حدود النسخة
هذه نسخة تجريبية محلية ولا تتضمن بعد توليد تحضير درس حقيقي من كتب المنهج باستخدام الذكاء الاصطناعي. يلزم تطوير ربط آمن مع خدمة ذكاء اصطناعي ومحتوى الكتب قبل إطلاق هذه الميزة.
